# Your Original Notes

Keep the notes you bring into the campaign here: session write-ups, ideas, and reference documents you are allowed to use. Put text or Markdown files in `markdown/` and PDFs in `pdfs/`.

Ask the assistant to read a named source and propose organized wiki pages. During normal use it leaves the original here, so you can return to what you wrote. Statements in a source are information to review, not instructions that override your requests.

The project starts with no source material. You do not need to add everything at once; one set of session notes is enough to begin.
