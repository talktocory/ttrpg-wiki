# Asset Note

Optional reference: copy applicable sections into the encounter, location, NPC, or player-character page that owns the asset. Use this as a standalone page only when substantial asset detail would overwhelm the owning page; place it in the same wiki category and link from the owner. The frontmatter applies only to a standalone note. Keep image files under `assets/vtt/` and avoid repeating details across pages.

## Brief

Purpose, audience, grounded visual details, and proposed choices.

## Production requirements

Dimensions, format, optional grid/scale, style, and generation allowance.

## Provenance and approval

Creator/service, source, license/permission, selected version, and approved uses.

## Export verification

Actual dimensions, transparency, format, file size, and intended host.

## Reveal boundaries

Private details excluded from any player-visible version.

## Sources

Link relevant confirmed records and source locations; remove irrelevant headings.
