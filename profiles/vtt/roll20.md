# Optional Roll20 Export Profile

Select explicitly; this is not the project default. For a square-grid map, agree footprint, distance per cell, and pixels per cell. A practical starting export is 70 pixels per cell; higher resolution is optional. A 20 by 15 cell map at 70 pixels per cell exports to 1400 by 1050 pixels. Verify actual image dimensions and scale after export. Do not infer any physical distance per square from the VTT.

PNG supports transparent tokens; 280 by 280 pixels is a useful optional portrait export. Token style and shape remain campaign choices. JPG can reduce opaque map file sizes. Verify current upload limits for the relevant account before promising compatibility.

References: [Roll20 file practices](https://help.roll20.net/hc/en-us/articles/360037256634-Best-Practices-for-Files-on-Roll20), [map art guidance](https://roll20partners.zendesk.com/hc/en-us/articles/10827672443159-Map-Art-Guidelines).
