# Optional Game and Map Guidance

A profile is a short note with extra guidance for your chosen game or virtual tabletop. You can ask the assistant to help prepare one and add its path to `campaign.yaml`. Skip this folder until you need it.

- [Game-system starting template](systems/system-template.md): record which rules and edition your table uses, house rules, and questions still to check.
- [Gridless and narrative play](vtt/gridless.md): ideas for games that do not need a tactical grid.
- [Roll20 image guidance](vtt/roll20.md): optional map and token export suggestions.

Profiles contain guidance, not rulebooks or installed tools. Your campaign settings and approved house rules take precedence over their suggested defaults.
