# Adventure Walkthrough: Timed Outline

Target running time: 10–12 minutes.

| Time | Section | Teaching goal |
| --- | --- | --- |
| 0:00–0:40 | Problem and result | Show the value of turning a published adventure into concise, navigable GM preparation. |
| 0:40–1:25 | Starting state | Confirm that the local Git repository is already configured and introduce `raw/`, `wiki/`, and `assets/`. |
| 1:25–2:25 | Add the adventure source | Show the authorized *Forgotten Circus* PDF or excerpt under `raw/pdfs/` and explain the focused ingestion scope. |
| 2:25–4:15 | Request focused ingestion | Ask the agent to ingest the selected overview, Act 1, and relevant NPC sections as unplayed preparation. |
| 4:15–6:15 | Review the proposal | Check destinations, source citations, Draft/Unused status, GM-only secrets, and the absence of played events. |
| 6:15–7:15 | Approve selected updates | Authorize the reviewed proposal and let the agent save the wiki updates. |
| 7:15–8:45 | Preview the preparation | Navigate the updated index, encounter, location, and NPC pages with Markdown Preview. |
| 8:45–10:15 | Inspect the Git diff | Compare the approved proposal with the actual changes, including the index and activity log. |
| 10:15–11:15 | Continue the workflow | Explain section-by-section ingestion and mention session preparation, player-safe recaps, maps, and tokens. |
| 11:15–12:00 | Close | Recap: name the source, review, approve, preview, and inspect. |

Tool installation and campaign initialization belong in the agent-specific companion videos.
