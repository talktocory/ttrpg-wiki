# VS Code and Codex Setup: Timed Outline

Target running time: 7–9 minutes.

| Time | Section | Teaching goal |
| --- | --- | --- |
| 0:00–0:30 | Outcome and prerequisites | Show the initialized local campaign that the viewer will create. |
| 0:30–1:20 | Verify Git and commit identity | Confirm that Git is installed, explain how to install it if missing, and verify the author name and email used for commits. |
| 1:20–2:15 | Download and extract | Download the latest release ZIP and extract it into a folder named for the campaign. |
| 2:15–3:00 | Open the folder and initialize Git | Open the folder containing `campaign.yaml`, initialize a repository, and commit the blank baseline. |
| 3:00–3:40 | Open the Codex IDE extension | Connect Codex beside the campaign files and identify the local workspace. |
| 3:40–4:40 | Install the local Python environment | Prepare the supported validation and image-processing dependencies without teaching Python. |
| 4:40–5:20 | Confirm workspace access | Verify that Codex can read and save the intended campaign folder without changing it. |
| 5:20–7:15 | Initialize the campaign | Use `ttrpg-campaign-init`, answer essential questions, and review the exact proposal. |
| 7:15–8:20 | Approve and inspect | Save the approved settings, inspect the Git diff, and commit the campaign configuration. |
| 8:20–9:00 | Handoff and backup note | Point to the adventure walkthrough and mention optional private remote backup. |

If dependency installation takes too long, replace the wait with a cut while leaving the command and successful result visible.
