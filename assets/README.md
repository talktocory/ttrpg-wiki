# Your Maps, Tokens, and Other Images

Keep private map files in `vtt/maps/` and token files in `vtt/tokens/`. Put the image link and useful notes—description, source, permission to use it, export settings, approval, and hidden details—on the relevant encounter, location, NPC, or character page.

For an unusually detailed asset, a separate linked note in the same wiki category can help. Avoid copying the same notes into several pages. The [asset-note template](../wiki/_templates/asset-note.md) supplies sections you can use on the owning page or in a substantial separate note.

Keep only separately reviewed player-visible images in `player-safe/`. Review what the image shows before sharing it; its folder name cannot make hidden details safe. The project includes no campaign images, and image creation depends on the tools available to your assistant.
